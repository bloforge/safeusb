# Changelog

## 0.1.0 (unreleased)

First working version.

- `list-devices` with system and removable flags
- `backup`, `restore`, `verify`, and `info` for `.safeusb` archives
- `flash` for ISO, img, and compressed images, with read-back verification and a progress bar
- Windows volume locking before raw writes
- `sum` for SHA-256 and BLAKE3, with check mode
- `inspect` for MBR and GPT partition tables

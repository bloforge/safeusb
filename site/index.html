SafeUSB

Cross-platform disk backup, restore, and USB flashing, written in Rust.

Source Releases Archive format

Check an image

Pick an ISO or image file and paste the SHA-256 published by its source. The file is read and hashed in this browser. Nothing is uploaded.

Why SafeUSB

  • Flashes ISO and disk images, including .gz, .xz, and .zst.
  • Reads every write back and checks it against the source.
  • Refuses the system disk and asks you to type the target path before writing.
  • Runs on Windows and Linux.

Install

cargo build --release
./target/release/safeusb list-devices

Windows zip and checksums are on the releases page.
